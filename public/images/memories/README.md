# Memories Gallery Images

Place your personal photographs here for Vanessa.

## How to add photos:

1. Add your photos to this folder:
   - `memory-1.jpg` (or `.png` / `.webp`)
   - `memory-2.jpg`
   - `memory-3.jpg`
   - `memory-4.jpg`
   - `memory-5.jpg`
   - `memory-6.jpg`

2. You can also customize captions, dates, and locations in:
   `src/data/memories.js`

3. If no custom image is found for a slot, the website automatically falls back to an elegant romantic starry illustration card so the website always looks stunning!
